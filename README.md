 Instagram Data Parser

This project extracts and processes Instagram profile data from raw text and converts it into structured JSON format.

## Features
- Extract username, posts, followers, following
- Convert followers (K, M) into numbers
- Store data in JSON file
- Find user with max posts and followers
- Identify different page categories

## Tech Used
- Python
- JSON

## How to Run
1. Place your data file
2. Run the Python script
3. Output will be generated in JSON format
